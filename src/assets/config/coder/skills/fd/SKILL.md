# fd

`fd [OPTIONS] [PATTERN] [PATH...]` は、PATH 以下を並列にたどり、名前が PATTERN（正規表現）に一致するファイルとディレクトリを出す。ignore ファイル（`.gitignore`、グローバルな git の ignore、`.ignore`、`.fdignore`）が除外するパスと、隠しファイルは対象にしない。

## find からの置き換え

| find での書き方 | fd での書き方 |
| --- | --- |
| `find . -name '*.swift'` | `fd -e swift`。`-e` を重ねるといずれかに一致する（`-e m -e h`） |
| `find . -name 'AppDelegate.swift'` | `fd -g 'AppDelegate.swift'`。`-g` は名前全体を glob で照合する |
| `find . -name '*Controller*'` | `fd Controller`。PATTERN は名前の一部に正規表現で照合する |
| `-iname` | 何も付けない。PATTERN が小文字だけなら大文字と小文字を区別しない。区別するときは `-s` |
| `-type f`、`-type d` | `-t f`、`-t d` |
| `-maxdepth N` | `-d N` |
| `find DIR -type f` | `fd -t f . DIR`。PATH だけを指定するときは PATTERN に `.` を書く |
| `-not -path '*/Pods/*'`、`-path ./Pods -prune -o` | ignore 済みのディレクトリ（依存パッケージ、ビルド成果物）と `.git` などの隠しディレクトリには何も付けない。追跡されているディレクトリは `-E Generated` のように `/` を含まない名前で除外する |
| `-exec CMD {} \;` | `-x CMD`。ファイルごとに 1 回ずつ、並列に実行する。実行順は保証されないため、順に実行するときや、同じファイルや状態を書き換えるときは `-j 1` を付ける |
| `-exec CMD {} +`、後段の `xargs CMD`、`-print0` と `xargs -0` | `-X CMD`。見つかったファイルをまとめて渡す。OS のコマンドラインの長さの上限を超えると、複数回に分けて実行される（`fd -e swift -X wc -l`） |
| `2>/dev/null` | 付けない。fd の標準エラーは、存在しないパスや PATTERN の誤りを伝える |

## 検索の組み立て

- PATTERN の `.` は任意の 1 文字に一致する。`.` や `+` を含む名前の一部をそのまま探すときは `-F` を付ける。
- ディレクトリで絞るときは PATH に渡す（`fd -e swift . src/views`）。PATTERN に `/` を含めるとエラーになる。パス全体に照合するときだけ `-p` を付ける（`fd -p -g '**/views/*.swift'`）。
- `-E` の glob は、`/` を含まなければどの階層の名前にも一致し、`/` を含むと PATH（検索の起点）からの相対パスに照合する。カレントディレクトリからの相対パスで書くと、PATH が異なるときに何も除外されない。
- `.github` などの隠しディレクトリにあるファイルを探すときは `-H -E .git` を付ける。`-H` だけでは `.git/` の中身も出る。ignore 済みのファイルは `-I`、両方は `-u` で対象にする。

## シェルでの指定

- PATTERN と glob は単一引用符で囲む。zsh では、引用符のない `*.md` は、一致するファイルがなければ `no matches found` でコマンドが実行されず、カレントディレクトリに一致するファイルがあればその名前に展開されて別の検索になる。拡張子は `-e` で指定すれば glob を書かずに済む。

## 既定の挙動

- PATTERN を省くと PATH 以下のすべてを出す。`fd src` は名前が `src` に一致するものを探し、`src` の中は列挙しない。
- 出力はカレントディレクトリからの相対パスで、ディレクトリの末尾に `/` が付く。PATH に `.` を明示したときと、`-x`、`-X`、`-0` を付けたときは先頭に `./` が付く。`-a` で絶対パスを出す。
- 並列にたどるため、出力の順序は実行ごとに変わる。順序が要るときは `sort` に渡す。
- 一致がなくても終了コードは 0 である。一致の有無で分岐するときは `-q` を付ける（一致ありで 0、なしで 1）。
