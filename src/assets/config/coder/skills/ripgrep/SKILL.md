# ripgrep

`rg [OPTIONS] PATTERN [PATH...]` は、PATH 以下を並列に再帰検索する。ignore ファイル（`.gitignore`、グローバルな git の ignore、`.ignore`、`.rgignore`）が除外するパス、隠しファイル、バイナリファイルは検索しない。

## grep からの置き換え

| grep での書き方 | rg での書き方 |
| --- | --- |
| `grep -rn PATTERN DIR` | `rg -n PATTERN DIR`。再帰は既定 |
| `--include='*.swift' --include='*.m'` | `-t swift -t objc`。`-t` を重ねるといずれかに一致する。組み込みの種類は `rg --type-list` で確かめ、種類がない拡張子だけ `-g '*.plist'` を使う |
| `--exclude-dir=DIR`、後段の `grep -v DIR` | ignore 済みのディレクトリ（依存パッケージ、ビルド成果物）には何も付けない。追跡されているディレクトリは `-g '!DIR'` で、どの階層にあっても除外する。`grep -v` は行の内容にも一致し、必要な行も捨てる |
| 後段の `grep -v '^Binary'` | 何も付けない。バイナリファイルは既定で除外される |
| `2>/dev/null` | 付けない。rg の標準エラーは、存在しないパスと、絞り込みで検索対象が 0 件になったこと（`No files were searched`）を伝える |

PATTERN は `grep -E` と同じく、選択を `'a|b'`、グループを `'(a)'` と書く。grep の基本正規表現の `\|`、`\(`、`\{` は、rg ではその文字自体に一致するため、エラーにならないまま一致しなくなる。

## 検索の組み立て

- 追跡されているノイズ（取り込んだ外部コード、生成コード）は、出力に現れた時点で `-g '!3rdParty'` のように除外し、同じ作業の以降の検索でも付ける。
- 識別子の参照は `-w` で探し、より長い識別子の一部としての一致を除く。
- 正規表現の記号を含む文字列をそのまま探すときは、エスケープせずに `-F` を使う。
- 一致した行の周辺を読むときは、行番号を検索してから別のコマンドで範囲を表示せず、`-n -C NUM` で検索と表示を 1 回にする（`rg -n -C 20 'func play' src/Player.swift`）。
- 結果の規模が読めない検索は、`-l`（一致したファイル）か `-c`（ファイルごとの一致行数）で分布を見て、パスと種類で絞ってから本文を出す。`| head` で打ち切ると、並列検索のため、残る行は実行ごとに異なる任意の部分になる。
- 1 行が長いファイル（圧縮された JS、JSON、Interface Builder の XML）を含む検索には `-M 300 --max-columns-preview` を付け、長い行を先頭 300 バイトに切る。

## シェルでの指定

- PATTERN と glob は単一引用符で囲む。zsh では、引用符のない `*.swift` に一致するファイルがないと `no matches found` でそのコマンドが実行されず、`;` で続けた他のコマンドの出力だけが返るため、結果の欠落に気づきにくい。
- PATH を明示する（`rg -n foo .`）。PATH を省略すると、標準入力がパイプかファイルのときは、ディレクトリではなく標準入力を検索する。

## 既定の挙動

- 出力先が端末でないときは、各行を `パス:内容` の形で出し、行番号、見出し、色を付けない。一致した位置を参照するときは `-n` を付ける。
- PATH に明示したファイルとディレクトリは、ignore の対象でも検索する。`.tmp/` のような ignore 済みのディレクトリは PATH に渡す。
- `-g` と `-t` は ignore と隠しファイルの除外を解除しない。隠しファイルは `--hidden -g '!.git'`、ignore の対象は `--no-ignore`、両方は `-uu` で検索する。
- glob は `.gitignore` の規則で照合する。`/` を含まない glob はどの階層の名前にも一致し、`/` を含む glob はカレントディレクトリからの相対パスに一致する。複数の `-g` が同じパスに一致すると、後に書いたものが優先される。
- 大文字と小文字を区別する。`-i` は区別せず、`-S` は PATTERN が大文字を含まないときだけ区別しない。
- 終了コードは、一致ありで 0、一致なしで 1、エラーで 2 である。

## その他のオプション

| オプション | 効果 |
| --- | --- |
| `-A NUM` / `-B NUM` / `-C NUM` | 一致した行の後 / 前 / 前後の NUM 行も出す |
| `-o` | 一致した部分だけを出す |
| `-e PATTERN` | 重ねると、いずれかに一致する行を出す。`-` で始まる PATTERN もこれで渡す |
| `-v` | 一致しない行を出す。コマンドの出力を絞るときに使う |
| `--files` | 検索対象のファイルを列挙する |
