# クールテクニカル

## 印象

冷たい紙面のような中立面とインディゴを基調にし、精密で落ち着いた技術文書の印象をつくる。橙は優先度や注意を必要とする情報だけに使う。ライトとダークで色の役割を変えず、明度関係を反転する。

## 適用

キャンバスは純白や純黒を避け、表面との小さな明度差で奥行きをつくる。主色はリンク、主要操作、選択状態、現在の状態に使う。シグナル色は優先度、注意、変更前の状態など、意味を限定して少量だけ使う。装飾目的のグラデーションや多色アクセントは加えない。

ライトテーマの影は `0 1px 2px rgba(18,22,31,.06), 0 8px 24px rgba(18,22,31,.05)`、ダークテーマの影は `0 1px 2px rgba(0,0,0,.35), 0 8px 28px rgba(0,0,0,.4)` を基準にする。
